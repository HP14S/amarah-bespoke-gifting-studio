# Amarah Bespoke Gifting Studio

Build the House of Amarah gifting studio website based on https://amarah-gifts-and-glow.lovable.app and https://www.instagram.com/house_of_amarah_official__/

Logo & Header:
- Create a clean transparent-background brand logo featuring the delicate pink butterfly mark cleanly aligned beside the elegant serif text "House of Amarah" (beautifully composed and aligned, not a square profile picture).
- Clean, sticky header with navigation anchors (Home, Offerings, Approach, Contact) and an inquiry CTA.

Offerings Section:
- Remove the 01/02/03 numbers.
- Remove the "See on Instagram" overlay from every image.
- Instead, add a small, tasteful tag on each image (e.g. "Hand-poured", "Personalised", "Curated Keepsake", "Bespoke").
- Scented & Wellness Candles: Use an editorial collage layout with one large feature image + two smaller supporting images.
- Books & Literary Gifts: A large image with descriptive text beside it (alternating editorial layout).
- Custom Invitations & Occasion Gifts: A tall portrait image layout with details.
- Gift Hampers (Return Gifts, Custom Hampers, Festival Hampers): Side-by-side cards.
- Change every "Check price" button to "Ask for Price", linking to WhatsApp (https://wa.me/...) with a prefilled message specifying the product name (e.g., "Hello House of Amarah! I would like to ask for the price of [Product Name].").
- Add a "View more on Instagram" link at the end of the Offerings section linking to https://www.instagram.com/house_of_amarah_official__/.

Design & Styling:
- Keep the warm luxury aesthetic: soft ivory/linen background, warm stone cards, blush/terracotta accents, charcoal text, elegant Cormorant Garamond serif headings, and clean DM Sans typography.
- Include the hero section, studio introduction, offerings, bespoke gifting approach, and footer with social links.
